# Pose Estimator and Fitness Tracking Tools

A set of computer vision tools built on MediaPipe Pose for tracking body landmarks in video and using them for basic fitness applications.

## Included
- Pose_estimator.py - core pose landmark detection and drawing on video
- - squat_counter.py - counts squat reps from pose landmarks
  - - Push_ups.py - counts push-up reps
    - - Posture_analysis.py - basic posture/alignment analysis
     
      - ## Tech stack
      - Python, OpenCV, MediaPipe
